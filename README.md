# Data Processing Tool

## 项目描述

这是一个用于数据加载和基础分析的工具，能够智能处理不同类型和大小的数据文件，并提供全面的数据基础分析功能。

## 功能特性

### 1. 数据加载（Load Data）

- **1.1 数据类型识别**
  - 自动识别数据文件类型（csv/xlsx/tsv等）
  - 对不支持的文件类型给出明确提示

- **1.2 智能加载策略**
  - 根据文件大小采用不同的加载方式：
    - 小于500MB：直接完整加载
    - 500MB - 10GB：分批次加载
    - 大于10GB：仅加载前500MB数据

- **1.3 数据格式转换**
  - 将加载的数据转换为DataFrame格式，便于后续分析

### 2. 数据基础分析（Data Basic Analysis）

- **2.1 数据规模分析**
  - 统计数据的行数和列数
  - 若无法完全加载，仅展示已加载部分的列数

- **2.2 列信息分析**
  - 显示所有列名（或已加载部分的列名）
  - 分析每列的数据类型（int、float等）
  - 判断数据分布类型（离散/连续）

- **2.3 缺失值分析**
  - 统计每列缺失值的数量
  - 计算缺失值占该列总数的百分比

- **2.4 重复值分析**
  - 统计每列重复值的数量
  - 计算重复值占该列总数的百分比

- **2.5 数据分布分析**
  - **离散数据**：统计每个数值的频数和占比
  - **连续数据**：计算均值、中位数、标准差、最小值、25%分位数、50%分位数、75%分位数和最大值

## 安装要求

- Python 3.6+
- pandas
- numpy

## 使用方法

```python
# 导入数据处理工具
from data_process import DataProcessor

# 创建数据处理器实例
processor = DataProcessor()

# 加载数据
df = processor.load_data('path/to/your/data.csv')

# 进行基础分析
analysis_results = processor.basic_analysis(df)

# 查看分析结果
print(analysis_results)
```

## 注意事项

- 对于超大文件（>10GB），仅加载前500MB数据，分析结果可能不代表完整数据集
- 支持的文件类型：CSV、XLSX、TSV等常见结构化数据格式
- 分析结果会以字典形式返回，包含所有分析指标
